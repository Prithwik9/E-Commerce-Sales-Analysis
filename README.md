# E-commerce Sales Analysis Dashboard

## Project Overview
This project analyses a synthetic e-commerce dataset containing 1,500 orders, 100 products, and 300 customers. It uses spreadsheet analysis techniques to evaluate sales performance, profitability, customer segments, sales channels, order fulfilment, and data quality.

The objective is to transform raw transactional data into actionable business insights through formulas, pivot tables, and an interactive dashboard.

## Tools Used
- LibreOffice Calc
- Excel-compatible `.xlsx` workbook format
- Spreadsheet formulas and lookup functions
- Pivot tables and charts
- Data validation and quality checks

## Project Features
- **Data Quality Checks:** Checks for duplicate records, missing IDs, invalid values, and incorrect customer or product references.
- **Data Preparation:** Combines order, product, and customer information into an analysis-ready dataset.
- **Advanced Formulas:** Uses `INDEX`, `MATCH`, `SUMIFS`, `COUNTIFS`, `AVERAGEIFS`, `IF`, `IFERROR`, and nested conditional logic.
- **Pivot Table Analysis:** Summarises revenue by category, city, sales channel, and customer segment; analyses profit by category and order status.
- **Dashboard:** Presents key performance indicators (KPIs) and six charts for a quick overview of business performance.
- **Business Insights:** Highlights leading categories, cities, channels, customer segments, and order fulfilment patterns.

## Key Business Insights

1. **Top Revenue Category — Appliances:** Generated 589,663.30 in revenue.
2. **Top Profit Category — Fashion:** Generated 166,824.65 in profit.
3. **Leading Sales Channel — Mobile App:** Recorded 1,084,542.65 in revenue.
4. **Leading Customer Segment — Returning Customers:** Contributed 1,296,792.50 in revenue.
5. **Top Revenue City — Visakhapatnam:** Generated 151,701.05 in revenue.
6. **Order Fulfilment:** Out of 1,500 orders, 1,078 were delivered, 161 shipped, 99 were processing, 89 were cancelled, and 73 were returned. Cancellations and returns together accounted for 10.8% of all orders.

*Note: Financial figures are reported from the project's analysis tables. Refer to the workbook for the underlying calculations and order-status definitions.*
